# Agent Rules & Guidelines

## Strict Execution Constraints

1. **No Git Commands**:
   - Do NOT run any `git` commands (e.g., `git commit`, `git push`, `git checkout`, `git rebase`, `git reset`, `git status`, etc.) unless explicitly instructed by the user.

2. **No UI Testing / Browser Subagents**:
   - Do NOT run any browser automation, UI testing, or launch browser subagents unless explicitly asked by the user.
